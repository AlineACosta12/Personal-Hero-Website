# Personal Hero Website (Client-Side Web Development)

## Description
A multi-page website created for a first-year Client-Side Web Development assignment. The site presents research and content about a personal hero, using structured navigation across pages, consistent styling, and basic JavaScript interactivity.

## Features
- Multi-page navigation (e.g., About Me, Impact, Multimedia, Sources, etc.)
- Responsive layout using CSS
- JavaScript used for simple interactivity (where applicable)
- Images and multimedia content included

## Technologies
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.

## Folder / File Overview (example)
- `index.html` — home page
- `style.css` — site styling
- `script.js` — JavaScript functionality
- `Images/` — images used across pages

## Project Status
Completed (first-year assignment).
